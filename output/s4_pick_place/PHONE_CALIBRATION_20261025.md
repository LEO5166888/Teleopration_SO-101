## 契約與限制

本次候選：base_delta = gain * [XR_x, XR_y, -XR_z]。
右 -> -base X、左 -> +base X、前 -> -base Y、後 -> +base Y、上 -> +base Z、下 -> -base Z。
這是本次手機朝向／XR 工作階段的經驗校正，不是 WebXR 通用座標定義。
未實作任意手機朝向、重建 reference space 的自動校正。
保留輸入中偏軸移動，未加入濾波或只取最大軸，因此不承諾消除所有斜走。

## 可重跑測試

在此資料夾執行：

```bash
python3 -m unittest -v test_phone_translation_20261025.py test_s4_task_logic.py test_s4_jog_transport.py
```

新測試先對原版映射執行：六筆實測方向與六筆理想單軸案例共 12 個子案例失敗，零輸入通過。
候選另用 map_calibrated_webxr_translation_to_base；主程式明確接到該函式。
舊 map_webxr_translation_to_base 留給未啟用的 tool-heading helper 與歷史回歸測試。
測試通過只代表數值符合本次方向契約，不等於實際機器人已通過驗收。
